⚠️  REGRAS CRÍTICAS (SIGA À RISCA)

  1. Diagnóstico antes de fix (não suponha)
  2. Cada fix pequeno (um problema = um commit)
  3. Teste em VM obrigatório (não confie só em build)
  4. Nenhum secret no binário (brain.env é env var)
  5. Rollback sempre disponível (git revert HEAD --no-edit)

════════════════════════════════════════════════════════════════════════════════

✅ CHECKLIST FINAL (QUANDO PARAR)

  Quando TODOS estes itens forem ✓, o installer está pronto:

    ☐ Backend compila (cargo build --release OK)
    ☐ Frontend builda (npm run build OK)
    ☐ ISO buildada (~600MB gerada)
    ☐ Kiosk lança em VM (interface web visível)
    ☐ Web renderiza (formulários visíveis)
    ☐ Backend responde (http://localhost:8080/api/health = 200)
    ☐ Navegação funciona (clique "Próximo" funciona)
    ☐ Formulários funcionam (preenchimento, validação, envio)
    ☐ Instalação completa (VM rebooteia, NixOS funciona)
    ☐ Logs limpos (sem "failed", "Connection refused")
    ☐ Código limpo (sem TODOs, imports válidos)
