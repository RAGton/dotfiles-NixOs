# Kryonix Mascot Concept

Objetivo: conceito inicial de mascote para a linha visual Kryonix Blue Glass.

Direção:
- Forma geométrica limpa, com silhueta própria.
- Linguagem visual técnica: placas, visor, linhas luminosas azul/ciano.
- Sem copiar mascotes conhecidos de Linux, Windows ou macOS.
- Deve funcionar em wallpaper, avatar, sticker e splash.

Notas:
- Tema: infraestrutura, precisão, IA local, frio técnico, vidro e luz.
- Personalidade: calmo, analítico, confiável.
- `playlist_status = UNKNOWN`; esta nota não usa a playlist como referência técnica.
