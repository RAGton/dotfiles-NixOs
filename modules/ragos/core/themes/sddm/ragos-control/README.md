# RAGOS Control SDDM

Tema canônico do SDDM para o cliente RAGOS.

Objetivo:

- greeter dark com cara de produto;
- card de login sólido e previsível;
- hostname, perfil e transporte visíveis;
- mesma linguagem visual do wallpaper institucional e do logo do boot.

Guardrails:

- sem base visual de Windows;
- sem neon, blur ou transparência espalhafatosa;
- sem depender de telemetria de rede em tempo real que o tema não entrega.
